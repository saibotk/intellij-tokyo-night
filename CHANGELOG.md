# Changelog

## [v0.0.2] - 2026-07-05

### Added

- Colors for the new Terminal

### Changed

- Removed maximum version support, allowing the plugin to be compatible with future versions of IntelliJ IDEA and PhpStorm.

## [v0.0.1]

- Initial release of the IntelliJ Tokyo Night theme plugin, based on the popular VS Code theme Tokyo Night by enkia, with adjustments for PHP and PhpStorm 2024.1. Includes both an editor theme and a matching color scheme.
